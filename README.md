# SVTestTask

Автотесты публичного сайта [icons8.com](https://icons8.com) на Playwright и TypeScript.

## Структура

```
SVTestTask/
├── .cursor/
│   └── rules/
├── .github/
│   └── workflows/
│       └── playwright.yml
├── node_modules/
├── playwright-report/
│   └── index.html
├── test-results/
├── tests/
├── Техническое задание/
├── .env
├── .gitignore
├── eslint.config.mjs
├── package-lock.json
├── package.json
├── playwright.config.ts
├── tsconfig.json
└── README.md
```

## Папки

**.cursor** — правила для ИИ-помощника в редакторе Cursor. Они повторяют ограничения технического задания и не дают помощнику уйти в лишние правки и ошибки.

**.github** — настройки автоматической проверки на GitHub. После каждой отправки кода сервис GitHub Actions сам ставит библиотеки и запускает проверку кода.

**node_modules** — скачанные библиотеки, без которых не запускаются тесты и проверка кода. Папка не отправляется в GitHub: она создаётся заново при установке.

**playwright-report** — отчёт последнего запуска тестов на этом компьютере. Файл `index.html` открывается в браузере и показывает, какие проверки прошли.

**test-results** — запись шагов последнего запуска. Запись лежит в файле `trace.zip`: по ней видно, что делал браузер.

**tests** — автотесты. Playwright берёт отсюда сценарии и выполняет их в браузере.

**Техническое задание** — документ, по которому выполняется задание. Это исходные требования к проверке сайта.

## Файлы

**.env** — адрес сайта, логин и пароль для запуска тестов. Логин и пароль пустые, файл в GitHub не отправляется.

**.gitignore** — список того, что Git не берёт в сохранение. Закрыты библиотеки, файл `.env` и папка с техническим заданием.

**eslint.config.mjs** — правила проверки кода до запуска браузера. Проверка ищет ошибки в TypeScript и в тестах Playwright.

**package.json** — имя проекта, список библиотек и команды запуска. `npm run lint` проверяет код, `npm test` запускает автотесты.

**package-lock.json** — точные версии установленных библиотек. По нему на другом компьютере и в GitHub Actions ставятся те же версии.

**playwright.config.ts** — настройка автотестов. Здесь заданы обычный Chrome с окном, не больше двух браузеров сразу, адрес сайта, отчёт и запись шагов.

**tsconfig.json** — настройка языка TypeScript для редактора и проверки типов. Отдельные файлы из него не собираются: сценарии запускает Playwright.

**README.md** — этот файл. В нём схема проекта и короткое описание папок и файлов.
